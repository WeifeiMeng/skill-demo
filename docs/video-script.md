## 详细文案

### 1. 开场（15s）

> AI 时代来了，但一个问题始终没有被回答——**一个人的 AI 协作能力，到底怎么衡量？**
>
> 这就是 AI Done。一个评估和提升 AI 协作解决问题能力的在线平台。

### 2. 痛点切入（30s）

> 传统的技术面试，还在问算法题、背八股文。但真正的职场里，没有人禁止你用 AI——问题是，你用得好不好？
>
> 同样是写代码、做数据分析、写方案，有人能用 AI 半小时搞定，有人花一整天。这项能力差距，在简历上完全看不出来。
>
> AI Done 要做的，就是让这项能力**可见、可评估、可提升**。

### 3. C端产品演示（90s）

**落地页 → 题库：**

> 进入首页，你会看到清晰的定位：个人学习者 vs 企业招聘两条线。点击「立即体验」，进入题库。所有题目按难度、标签分类——从 AI 编程到数据分析、自动化、创意生成，四个赛道全覆盖。

**进入考试 —— Docker 沙箱环境：**

> 选择一道题，系统在 3-5 秒内为你准备好一个**完整的在线开发环境**——不是模拟器，而是一个真实的 VS Code，跑在 Docker 容器里，预装了 Python、Node.js、Claude Code CLI。
>
> 左侧是题目描述，右侧是真实的 IDE。你可以在里面使用 AI 助手协作完成项目。右上角倒计时 120 分钟，跟真实工作场景一样——有时间压力、有质量要求。

**自动评分：**

> 完成后点击提交，系统自动跑测试用例评分。整个流程模拟了「拿到需求 → AI 协作 → 交付结果」的完整链路。

**题解广场、竞赛、排行榜：**

> 做完题还能去题解广场看别人的思路，参加竞赛和别人同台竞技，排行榜有段位系统——通过率、得分、胜率，一目了然。

### 4. 企业/管理端演示（60s）

> 这是企业招聘的场景。在落地页点击「企业招聘」→「创建考核」，进入管理后台。

**仪表盘：**

> 仪表盘看到全局数据——考生数、通过率、每道题的详情。

**题目管理：**

> 题目管理支持 Markdown 编写题目、配置测试用例、上传附件。企业可以根据自己岗位的需求，定制考核内容。

**考试管理：**

> 到这里创建考试场次——选择题目、设置时间、指定考生。创建后生成专属考试链接。

**实时监控与评卷：**

> 考试进行中，后台可以看到每个人的实时状态。结束后自动评分，生成评估报告——不是看代码行数，而是看**你用 AI 协作解决问题的效率和效果**。

**考生数据：**

> 每个考生的详细档案：完成题数、通过率、每道题的提交次数、用例通过情况。可以重置时间让考生重新答题。

### 5. 技术亮点（30s）

> 简单说一下背后是怎么跑的：
>
> 每个考生每道题，启动一个**独立的 Docker 容器**，挂载专属工作目录。容器里跑的是 code-server（VS Code 的 Web 版），预装了 AI CLI 工具。端口随机分配在 20000-30000。
>
> 前端 Vue 3，后端 FastAPI，数据库 MySQL，JWT 认证。整个系统可以在本地一键 `docker compose build` + `npm run dev` + `uvicorn` 跑起来。

### 6. 收尾（15s）

> AI Done——让 AI 协作能力，不再是嘴上说说。
>
> 无论你是想提升自己的 AI 使用能力，还是企业想招到真正会用 AI 的人，这里都有答案。

## 录制建议

- **工具**：OBS Studio，录制浏览器窗口 1920×1080（16:9）
- **配音**：建议单独录制音频后合成，或使用 TTS 工具生成旁白
- **字幕**：建议配上中文字幕，关键名词保留英文
- **背景音乐**：轻量电子/科技感背景音乐，音量低于人声
- **时长控制**：如果超时，优先精简第 3 章（C端演示），保留第 4 章（企业端）作为差异化亮点
