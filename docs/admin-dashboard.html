3 数据库变更

3.1 users 表 — 添加 role 字段

ALTER TABLE users ADD COLUMN role VARCHAR(20) DEFAULT 'user';
-- 值: 'user' | 'admin'
-- 首次管理员通过 SQL 直接设置: UPDATE users SET role='admin' WHERE ...

3.2 exam_results 表 — 新建

CREATE TABLE exam_results (
    id          INT AUTO_INCREMENT PRIMARY KEY,
    user_id     INT NOT NULL,
    article_name VARCHAR(255) NOT NULL,
    score       INT DEFAULT 0,
    max_score   INT DEFAULT 100,
    passed      BOOLEAN DEFAULT FALSE,
    cases_json  TEXT,
    submitted_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
);

4 API 端点

方法路径认证说明
GET /admin/dashboard admin 总览统计：总考生数、总提交数、通过人数、整体通过率、每题通过率
GET /admin/articles admin 题目列表（含 readme 内容、test_config、附件列表）
POST /admin/articles admin 新建题目（创建目录 + readme.md + test_config.json + attachments/）
PUT /admin/articles/{name} admin 更新题目的 readme.md 和 test_config.json
DELETE /admin/articles/{name} admin 删除整个题目目录（shutil.rmtree）
POST /admin/articles/{name}/attachments admin 上传附件文件（已做路径穿越防护）
DELETE /admin/articles/{name}/attachments/{filename} admin 删除附件
GET /admin/students admin 考生列表：每人完成题数、通过数、通过率
GET /admin/students/{user_id} admin 考生详情：各题目答题记录、每次提交分数、测试用例结果

认证流程

管理员与用户共享 /auth/login 登录入口。JWT payload 中包含 role 字段：

{
  "sub": "2",
  "email": "admin@test.com",
  "role": "admin",          // 关键字段
  "exp": 1781018761
}

所有 /admin/* 路由通过 get_admin_user 依赖检查 role != "admin" → 403。

def get_admin_user(user: User = Depends(get_current_user)):
    if user.role != "admin":
        raise HTTPException(status_code=403, detail="Admin access required")
    return user

exam_result = ExamResult(

ExamResultDao.create(exam_result)
