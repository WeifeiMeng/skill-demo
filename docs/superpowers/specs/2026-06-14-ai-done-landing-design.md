# AI Done 产品主页设计

## 概述

为 AI Done 平台创建产品主页（Landing Page），替代当前默认的题目列表页作为网站首页。

- **产品名：** AI Done
- **定位：** 评估和提升每个人利用 AI 技术解决问题的能力
- **双场景：** 个人学习者（提升 AI 实战能力）/ 企业招聘（评估候选人）
- **现有题目页：** 降级为二级页面 `/challenges`，通过主页底部按钮进入

## 路由调整

| 路由 | 组件 | 说明 |
|---|---|---|
| `/` | `Landing.vue`（新建） | 产品主页 |
| `/challenges` | 原 `Home.vue` 内容 | 题目列表页，替代原 `/` |
| `/exam/:filename` | `Exam.vue` | 不变 |
| `/completed/:filename` | `Completed.vue` | 不变 |

## 页面结构

### 整体布局

```
┌─────────────────────────────────────┐
│            NavBar（已有组件）         │
├─────────────────────────────────────┤
│            Hero 区                   │
│    AI Done（大标题）                 │
│    评估和提升每个人利用 AI 技术       │
│    解决问题的能力（副标题）           │
├─────────────────────────────────────┤
│         双角色分流卡片               │
│  ┌──────────┐  ┌──────────┐        │
│  │ 个人学习者  │  │ 企业招聘   │        │
│  │ 提升 AI   │  │ 评估候选人  │        │
│  │ 实战能力   │  │ 真实项目能力│        │
│  │ [开始学习] │  │ [创建考核]  │        │
│  └──────────┘  └──────────┘        │
├─────────────────────────────────────┤
│         平台简介（2-3 句）           │
├─────────────────────────────────────┤
│     [ 点击进入 Vibe Coding Online ]  │
│          醒目大按钮                  │
└─────────────────────────────────────┘
```

### 区域详情

**1. Hero 区**
- 大标题 "AI Done"，使用醒目的字体和渐变色
- 副标题 "评估和提升每个人利用 AI 技术解决问题的能力"
- 可选：微妙的动态背景（CSS 渐变或动画）

**2. 双角色分流卡片**
- 两张大卡片并排，各含 icon、标题、描述、按钮
- 个人卡片：icon（用户/学习）+ "个人学习者" + "通过实战题目提升你的 AI 驱动开发能力" + "开始学习" 按钮 → 跳转 `/challenges`
- 企业卡片：icon（建筑/企业）+ "企业招聘" + "用真实项目场景评估候选人的 AI 问题解决能力" + "创建考核" 按钮 → 跳转 `/challenges`（后续可扩展企业管理后台入口）
- 按钮暂不实现独立功能，企业按钮也可先跳 `/challenges`

**3. 平台简介**
- 简短文案：说明 AI Done 是一个让每个人都能够使用 AI 技术完成实际项目的平台，无论你是想提升自己的 AI 协作能力，还是想为团队找到真正能用 AI 解决问题的人才

**4. 底部 CTA**
- 醒目的大按钮 "点击进入 Vibe Coding Online"
- 点击跳转到 `/challenges`（原题目列表页）

## 组件设计

### 新建文件

- `frontend/src/Landing.vue` — 产品主页组件

### 修改文件

- `frontend/src/router.js` — 新增 `/` → Landing，原 Home 移至 `/challenges`
- `frontend/src/Home.vue` — 不需要改动内容，仅路由变更

### 依赖关系

```
Landing.vue (新)
  ├── 纯 HTML/CSS，无外部组件依赖（NavBar 由 App.vue 统一管理）
  └── 使用 vue-router 的 useRouter 进行跳转

router.js
  ├── import Landing from './Landing.vue'
  ├── { path: '/', name: 'landing', component: Landing }
  └── { path: '/challenges', name: 'challenges', component: Home }
```

## 视觉风格

- 与现有一致：深色文字 `#1e293b`，灰色辅助 `#64748b`
- 主色调：品牌色（建议蓝色或紫色渐变，待确认）
- 两个角色卡片使用区分色，hover 时有微动效
- 底部 CTA 按钮使用主色填充，圆角，较大字号

## 不包含的内容

- 不涉及后端 API 变更
- 不涉及 NavBar 变更
- 企业卡片暂不实现独立的企业管理功能入口（后续扩展）
- 不考虑移动端响应式（仅为桌面端优化）
